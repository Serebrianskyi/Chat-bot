# Implementation plan — 2026-10-20

Current state and what is left, as points. Supersedes the "Not built" list in `CLAUDE.md` as the
working order; the authoritative scope documents are unchanged.

## Done

### Money
- Onboarding at `/start`: register, resolve price, write due date, invoice on the spot
- Pricing: 10 EUR base; tiers discounted / in-community / new joiner
- Discounts: percent or fixed, optional expiry, soft revoke, computed **per invoice**
- WayForPay `CREATE_INVOICE` + `CHECK_STATUS` polled every 2 min, signature verified both ways
- `refine_status`: a `Declined` with no amount and no cardPan is **not** a refusal — the bug that
  wrote off 77 orders a minute after issuing them
- Order references suffix on collision (two invoices for one member in the same second)
- Idempotent on repeat `Approved`; amount checked against that member's own price
- Raw gateway bodies persisted before any business logic
- **Renewal reminder** a day before: balance warning with a card on file, a live pay link without
- **Two declines then cancel**, a day apart, with the owner's wording for each
- **`CHARGE` renewal path**: charges the stored `recToken` for anyone with a card on file;
  declined is told and not retried for 24 h, matching what `CHARGE_FAILED` promises. **Inert
  until a token can be obtained** — see item 1

### Access
- Single-use 3-day channel invite on a confirmed payment; every failure path tells somebody true
- 🔗 Надіслати запрошення — admin sends a link by hand, by `@username` or numeric id
- Daily recovery sweep at **11:00 Europe/Warsaw**: reconcile written-off orders, credit whoever
  really paid, link anyone paid-up who is outside the channel, escalate what it cannot fix
- One admin report per sweep; refuses to repeat inside 20 h, so deploys do not spam
- Covers lapsed payers who were never sent a link at all
- **Removal**: ban-then-unban anyone whose access and grace have both run out, admins spared,
  **off unless `REMOVAL_ENABLED`** — with it off the job reports who would go (G3.8)

## How to settle item 1 yourself — one 1 € test

The undocumented question is whether `CHECK_STATUS` returns `recToken` for a paid invoice. It can
be answered with one real payment, in about five minutes, without any code change:

1. **Issue yourself a 1 € invoice.** 📣 Розсилка → ♾ Безстрокові → any text → 🎟 Спеціальна ціна →
   `1` → 1 місяць → Надіслати. That group is your own account, and the flow is identical to a
   real campaign, so the invoice and the button are real.
2. **Pay it** with a real card.
3. **Wait up to two minutes** for the poller, or force it: `run_jobs poll`.
4. **Look at what the gateway actually sent:**
   `python -m scripts.diagnose order <order_reference>` — order references are printed by
   `diagnose reasons`. The command prints the stored body in full (the signature withheld, S5)
   and says outright whether `recToken` is in it.

- **Token present** → no webhook needed. Harvest it onto the subscription and `attempt_charge`
  takes over for every future period.
- **Token absent** → the token only ever arrives at `serviceUrl`, and automatic renewal needs the
  Phase 4 webhook. No payload change can shortcut it.

`python -m scripts.diagnose fields` answers the wider version of the same question: every field
WayForPay has ever sent across all stored bodies, flagged `read` or `IGNORED`. It already finds
one we ignore — `qrCode`, a payment QR image URL, which would let a member pay by scanning
instead of tapping a link.

Afterwards: revoke the 1 € discount in 🎟 Знижки, or it governs your own renewals too.

## Open questions

  `decide_price` closes the offer on that date. Policy, not a bug.
- Daily `process_due_subscriptions` still DMs a payment link to every unpaid member every
  morning. Gate it to previously-paying members only?

  rather than one album. Needs batching middleware + `send_media_group`.

## Standing risks

- `.env` holds live production credentials; every local run touches production
- Channel membership outlives the subscription until `REMOVAL_ENABLED` is switched on
- Postgres is exercised only by CI and production; local is SQLite
